# 修复内容

原始压缩包与 Word 文档未修改。此目录是独立的修复副本。

1. 恢复三个工作区的有效 catkin CMake 入口，修复 FAST-LIO 消息生成依赖、默认构建类型，以及头文件函数的多目标重复定义。
2. 增加统一环境检查、依赖安装、顺序构建脚本。构建失败立即退出，避免尚未生成 devel 时 source。原 build.sh 转发至统一脚本。
3. Livox 使用随包完整 SDK 源码，移除 CMake 配置阶段的删除源码和自动 git clone。
4. 修复雷达每点时间单位和帧头首点时间；默认线数匹配 RSHELIOS_16P，保留并注明外参校准要求。
5. IMU 网络脚本默认只检查，网络和 USB 模块操作改为显式参数；不再写死 Jetson 内核路径或自动修改两个网卡。串口与波特率可由启动参数传入。
6. 定位恢复地图加载，对缺图、错类型、数量、时间、坐标系、点云与位姿增加检查；修复空地图、末帧与单关键帧边界。
7. 定位回调串行化共享状态，初始静止也可重试配准；首次接受地图配准前不发布全局位置。新增非有限变换与点数保护。
8. 新增建图关键帧 bag 导出器：同步取 FAST-LIO 世界点云和位姿，转换为 body 点云，保存匹配定位器的两类消息。已有地图不覆盖，失败或零数据不发布正式地图。
9. 建图输出改为用户指定的同名 maps/*.bag 与 maps/*.pcd；定位期间停止额外 PCD 累积，修正分段保存路径及保存日志。
10. 增加清晰的建图/定位启动脚本、中文 ToDesk 编译运行说明和本地验证记录。

此版本仍使用 FAST-LIO 里程计地图，没有增加回环优化、底盘遥控或跨任意场景的全局重定位保证。硬件网络、外参和初始化位置需要符合实际实验条件。
