# 手动速度、点云与轨迹更新

本轮仅修改本地代码，不连接、部署或操控机器人。

- 按最后确认值：手动 W/S 线速度上限 1.50 m/s，A/D 角速度上限保持 0.30 rad/s。自动实验二为 0.50 m/s、0.30 rad/s。
- 加速度仍为 0.20 m/s²：从零达到手动上限理论上至少 7.5 秒。更高速度尚未进行实车制动距离验证，原有 1 m 障碍阈值不代表已经验证了该速度的停车距离。
- 默认 `rear_obstacle_pause=false`，纯倒车不触发后方障碍暂停；转向区域和前方检测、失联及传感器故障保护保持。
- 点云横向拖动方向已反转；机器人 A/D 定义不变。
- 界面改为深灰基底、蓝色强调。点云保留高度色彩，停止键保留红色。
- 新增真实定位轨迹视图，最多保留 2000 个轨迹点；断连、时间倒退或定位跳变重新分段。轨迹采用独立俯视窗口，避免将未经外参转换的定位坐标强行叠到原始雷达点云上。
- PD 仍使用弧度误差和弧度/秒微分，角度归整到 ±π；Kp=0.8、Kd=0.08 保持。加入跨 ±π 边界测试，检查归一化不引入微分突变。手动驾驶不经过航向 PD，调高 PD 不会提高手动转速。

前端新样式和拖动方向在刷新后可用。轨迹需要更新机器人端的位姿消息及重启本地后端，新的手动限速也需要重新编译部署；本轮不自动做这些操作。

## 本地验证

- 5 项 Node 测试通过，包括真实位姿轨迹收集、轨迹容量及跳变清空、点云/轨迹消息不会覆盖控制状态、会话与停车逻辑。
- Windows MSVC 本机编译并运行状态机测试通过：自动上限 0.5 m/s、完整仿真轨迹、PD 阻尼与 ±π 边界、暂停恢复和限幅。
- ROS 集成脚本已更新到最新手动限速和后方策略，但本轮不连接机器人，尚未重新运行 ROS 集成测试；没有部署或验证实车高速行驶。
