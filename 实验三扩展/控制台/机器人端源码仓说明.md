## 检查版本

```bash
cd /home/nvidia/robot-experiments
git log -1 --oneline
git status --short
sha256sum 实验二/lab26/catkin_ws/src/basic_control/src/basic_control.cpp
sha256sum /home/nvidia/lab26/catkin_ws/src/basic_control/src/basic_control.cpp
```

最后两个哈希一致才表示这份控制器源码已同步到运行目录。要检查正在执行的二进制，还应核对 `/proc/<控制器PID>/exe` 与运行目录 `catkin_ws/devel/lib/basic_control/basicControl` 的哈希。

## 更新与编译

本机编辑、测试通过后，在 PowerShell 7 执行：

```powershell
& 'C:\Users\asus\AppData\Local\Microsoft\WindowsApps\pwsh.exe' -NoLogo -File 'C:\Users\asus\Desktop\机器人实验\控制台\Sync-RobotSource.ps1'
```

该入口打包源码，通过现有专用密钥上传，再执行 `控制台/sync_robot_source.sh` 更新仓库。若仓库存在未提交改动，同步会停止，避免覆盖机器人上手工修改的内容。脚本只更新源码仓，不改变当前实车服务。

实际部署要在车辆静止且无活动实验时进行：备份运行目录，将对应源码同步进去，在 `/home/nvidia/lab26` 执行 `bash build.sh`，确认编译和状态机测试通过，再重启控制台服务。不要同时运行两个 CAN 控制器。实验一的大型依赖工作空间已经位于 `/home/nvidia/lab1/slam_experiment`，新源码仓不会替换已编译的依赖。

## WASD 使用与故障提示

打开 Windows 项目根目录 `启动控制台.cmd` 后，点击“启用键盘驾驶”。它会先取得本窗口控制权、发送心跳，再等待机器人确认手动模式；成功后按住 W/S 前后运动、A/D 原地转向，松键停车。实验选择下拉框的焦点不会再吞掉 WASD；文本或参数输入框编辑时不接管打字。

若没有启用，界面直接显示定位、雷达、底盘反馈、底盘模式或遥控接管的具体阻塞原因。模式确认不发送运动速度，自动实验也需要另行显式启动。关闭前端使用根目录 `关闭控制台.cmd`，保持 SSH 独立。

原理与实验内容见仓库根目录 `项目导航.md` 和 `机器人运动原理入门.md`。
