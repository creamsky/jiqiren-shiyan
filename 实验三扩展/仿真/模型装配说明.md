# SCOUT MINI 装配坐标核对

实验三 Word 图 4.1 的自车标注为长 **65 cm**、宽 **55 cm**，这是现有 650 × 550 mm 规划轮廓的依据。实验二 Word 图 2.3 将三角形中央接口端标为**尾部电气面板**，包含电压表、拓展接口和电源按键。固定版本 STL 的这个端面位于原网格 **−Y**，另一端的长灯罩在 **+Y**。端面与原图对照见 [装配坐标核对.png](装配坐标核对.png)。

`robot_description.py` 在展开厂家 Xacro 后统一作装配适配，将车体网格的 **+Y 转到 ROS +X**，即绕 Z 轴旋转 **−π/2**。车体 visual、collision、惯性坐标原点和方向同步变换，原 STL、DAE 和厂家 Xacro 文件保留原样。

原 STL 四个悬挂末端的圆形轴承安装平面分别由 62 个三角面构成，平面中心坐标如下，单位米。

| 原 CAD 轴 | 圆形安装面中心 |
| --- | --- |
| X | −0.18252623、+0.15347376 |
| Y | −0.24424478、+0.20835333 |
| Z | −0.07424039 |

先加厂家原网格偏移 `(0.015, 0.0231316650320557, 0)`，再整体作上述旋转，得到前轮关节 X 为 `+0.231484995`、后轮 X 为 `−0.221113115`，左轮 Y 为 `+0.16752623`、右轮 Y 为 `−0.16847376`。关节锚定在安装面，保留厂家轮子碰撞体沿轮轴向外 `0.03 m` 的偏移、`0.084 m` 长度和 `0.08 m` 半径。

DAE 轮胎部件的轮轴局部 Z 范围为约 `[−0.002218, +0.081495] m`，整轮含内轴的范围为约 `[−0.046995, +0.085005] m`。这一区别用于核对安装面和轮胎中心的位置。所有轮子关节轴变换到车体坐标后沿横向 +Y，正角速度滚动对应车体向 +X 前进。

滑移转向插件按实际碰撞轮心投影设置 `wheelSeparation = 0.39599999 m`、`wheelbase = 0.45259811 m`。固定版本厂家配置原先使用 `0.58 / 0.49 m`，需与修正后的装配匹配。该几何转向换算仍须通过 Gazebo 实际直行及转向测量检验，轮胎侧滑还会影响实际角速度。

另一份 [松灵官方 scout_ros 模型](https://github.com/agilexrobotics/scout_ros/blob/master/scout_description/urdf/scout_mini.urdf.xacro) 使用 DAE 车体、车体旋转 `rpy="1.5707 0 -1.5707"`、轴距 `0.463951 m` 和轮距 `0.416503 m`。它与本工程固定的 STL 版属于不同描述，本文的安装面坐标从本工程固定 STL 提取，未混用另一模型的轮子几何。
