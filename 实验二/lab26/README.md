## 在 Windows 启动

双击项目根目录的 `启动控制台.cmd`，在浏览器 UI 中完成连接检查、实验启动、暂停、继续、停止和 WASD 手动控制。旧实验二启动、停止、检查与 PowerShell 脚本一起保留在 `归档/旧实验二入口/`，不作为常用入口。

启动入口会通过 SSH 连接 `nvidia@10.226.235.72`，启动雷达、IMU、FAST-LIO 定位及 RViz，再运行控制程序。实车开机并连到同一网络、遥控器 SWB 位于最上档、行驶通道清空后即可运行。每次启动均以本次停稳的位置和车头方向为起点。

控制顺序为：等待定位稳定 → 原地左转 45° → 等待角度稳定 → 沿目标直线行驶 5 米 → 线速度和角速度同时归零。当前工作源码线速度上限为 0.25 m/s，角速度上限为 0.30 rad/s；最低速度保持原设置，接近终点继续减速。在 UI 中开始新一轮任务前，确认上一轮已结束。

本目录是当前实验二工作源码，本地路径为 `实验二/lab26/`，实车兼容路径仍为 `/home/nvidia/lab26`。共享浏览器控制台入口为项目根目录 `启动控制台.cmd`，自动建立 SSH 隧道并运行实车控制台入口；详见项目根目录 `控制台/说明.md`。`配套代码/` 和 `验收资料/` 保留交付快照，不会自动同步新的控制逻辑。

新控制逻辑以雷达为中心检查运动方向：有效障碍点进入 1 m 范围时暂停，退出 1.2 m 外并稳定 2 秒后保留原任务进度自动续跑。它不识别人，仍保留半径小于 0.45 m 的自身过滤、高度绝对值超过 0.35 m 的点过滤及至少 3 点的触发条件，不能视作完整 1 m 球体检测。定位、雷达及底盘故障停车不会按普通障碍自动恢复。手动与自动互斥，WASD 按住移动、松开停车，失焦或心跳超时停车。

2026-11-07 已恢复专用 SSH 私钥并验证批处理登录，前一轮源码暂存编译与 Motion 测试通过；后续修改需要重新验证。下文 2026-11-05 实车结果属于历史版本，不代表本次提速、暂停续跑和手动控制已通过实车运动测试。

当前新增修改计划采用航向 PD，Kp=0.8、Kd=0.08，微分项使用滤波后的实测航向角速度；正常指令线加速度上限 0.20 m/s²，角加速度上限 0.60 rad/s²，保护停车立即归零。PD 与加速度限制的对应测试尚待完成，不能复用前一轮测试结果作为本次通过依据。

## 已修复的问题

- 使用实车实际实验目录，替换文档中的旧目录与错误定位启动命令；不再运行包含 eth1、eth2 和旧内核模块路径的 net.sh。
- 明确拼接各 ROS 工作空间的包和库路径，避免连续 source 相互覆盖，导致雷达或 IMU 包找不到。
- 定位使用 `fast_lio/fastlio_mapping`。实测雷达为 16 线，转换后的点时间范围约 0～0.1 秒，因此配置 scan_line=16、timestamp_unit=0。
- 原始 `/car_pose.theta` 实测输出为度，而原控制代码按弧度使用。修正版读取带时间戳的 `/Odometry`，从四元数计算弧度航向角。
- 使用明确的转向、直行、终止状态；以本次起点计算行驶距离，增加横向偏差反馈，终点停车同时归零线速度和角速度。
- CAN 帧清零初始化；检查底盘状态、故障、控制模式及 SWB 档位，加入定位/点云/CAN 超时、位姿异常、近处障碍和底盘无响应停车。
- CAN 控制反馈 0x01 并不单独保证允许运动；实测 SWB 下档时不响应运动指令，最上档时正常。程序同时检查 RC 档位。

近处障碍检测是本实验的附加停车保护，使用激光雷达附近的水平点云，不是完整避障导航。

## 实测结果

2026 年 11 月 5 日，在用户现场配合切换遥控器后完成：

- 原地旋转：定位角度变化约 45.05°，全程线速度指令为零。
- 随后直行：终点位移约 5.002 m，终点横向偏差约 -0.001 m。
- 雷达与定位约 10 Hz，IMU 约 100 Hz。
- C++ 状态机测试通过；隔离 ROS master 下的完整轨迹、定位断流、雷达断流、近处障碍和无效位姿测试均通过。
- 首轮完整实车运动分两段执行，记录为旋转 45.05°、直行 5.002 m。
- 用户遥控返回起点后，实际运行了 Windows 的双击入口；连接、传感器、RViz、CAN 接管与控制启动均正常，复测在转向开始时因近处障碍保护停车，未再次完成五米行驶。脚本在保护停车时明确返回失败状态，不能把启动成功当作实验完成。
- 加入连续一秒通道清空后再次复测，仍在转向时出现近处障碍点而停止；停车后的连续采样恢复为空。保留保护逻辑和日志，未把该次复测标为成功。

首轮直行的最大横向偏差约 4.5 厘米。角度和距离均为实车定位反馈值，并非外部测量真值。记录在实车 `~/lab26/logs/`，Windows 工作区的 `verification/` 保存关键副本。
