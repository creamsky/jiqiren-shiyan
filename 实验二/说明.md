# 实验二

本实验的当前工作源码、运行脚本和验证记录位于 [lab26](lab26/README.md)。原根目录 `lab26/` 已整体移入此处，未删除源码或历史记录。

日常操作使用项目根目录的共享入口 `启动控制台.cmd`。控制台接入实验一、实验二和实验二扩展，提供共享 ping、WASD 手动驾驶、三维点云及实际里程计轨迹。实验二支持自动任务暂停续跑。

## 做什么与操作

机器人从启动时的位置原地左转 45°，稳定后沿目标航向直行 5 m，完成即停车。先选择实验二并点击“准备”，等待传感器、定位和机器人屏幕 RViz 就绪，再点击“启动”。进度条显示目标直线上的行驶进度；转向阶段为 0%，不是整个实验的时间百分比。

暂停保留起点和目标，点击“继续”接着运行；停止或故障会锁定停车，需要重新准备并启动新任务。新任务以新位置为起点。全局 WASD 与实验选择无关，切换手动会暂停自动任务。

## 简单原理

航向误差归一化到 −π～π，避免跨过角度边界时绕远路。P 项按误差修正方向，D 项用滤波后的实际角速度抑制转动过冲；直行时再根据横向偏差修正目标方向。最后对速度限幅，并按实际控制周期限制速度变化。

## 当前参数与保护

| 参数 | 数值 |
| --- | --- |
| 自动直行速度上限 | 0.50 m/s |
| 手动 W/S 速度上限 | ±1.50 m/s |
| 自动及手动 A/D 角速度上限 | ±0.30 rad/s |
| 手动线加速度 | 0.60 m/s²，原 0.20 的三倍，约 2.5 秒达到上限 |
| 自动线加速度 / 角加速度 | 0.20 m/s² / 0.60 rad/s² |
| 航向 PD | Kp=0.8，Kd=0.08，导数滤波时间 0.15 s |

W/S 前后运动，A/D 原地左右旋转，松键立即归零。运动方向上的有效雷达点在 1 m 内触发暂停；1.2 m 范围清空持续 2 秒后自动续跑。纯倒车暂不启用后方暂停。点云检测有近车身和高度过滤，不识别人；雷达、定位或底盘反馈异常会故障停车。失焦或失去心跳也会停车。
